# Восстановление изображений и видео с использованием нейросетевого подхода без предварительного обучения

## О проекте

Данный репозиторий содержит исходный код дипломной работы **«Восстановление изображений и видео с использованием нейросетевого подхода без предварительного обучения»**.

В работе проведён анализ метода [**Deep Image Prior**](https://github.com/DmitryUlyanov/deep-image-prior), предложены способы повышения его эффективности для задачи восстановления изображений, а также разработана адаптация метода для восстановления видео со статичными масками.

### Улучшения для восстановления изображений

За основу была взята нейронная сеть, используемая в методе **Deep Image Prior** для задачи image inpainting.

Для повышения эффективности метода были внесены следующие изменения:

- Замена функции потерь **MSE** на **SSIM**
- Замена функции активации **LeakyReLU** на **SoftPlus**
- Добавление механизма **автоматической остановки обучения** вместо фиксированного количества итераций

### Адаптация для восстановления видео

После улучшения метода для работы с изображениями он был адаптирован для задачи восстановления видео.

Для этого были внесены следующие изменения:

- Добавлен компонент функции потерь, учитывающий **временную согласованность** между соседними кадрами
- Сокращено время выполнения одной итерации обучения за счёт использования **GradScaler**

### Датасет

Для оценки работы метода использовался датасет **DAVIS**.

Для каждого видео генерировалась случайная маска, после чего выполнялось восстановление повреждённых областей видео.

## Запуск

### Подготовка данных

Ноутбук `create-data.ipynb` предназначен для предварительной обработки видео перед передачей их в нейронную сеть.

С его помощью можно:

- выполнить предобработку видео;
- сгенерировать случайную маску для выбранного видео;
- подготовить данные для последующего восстановления.

### Восстановление видео

Ноутбук `video-inpainting.ipynb` содержит реализацию модели и позволяет выполнить восстановление видео.

### Структура данных

Папка `data` содержит следующие директории:

```text
data/
├── DAVIS/       # исходные видео из датасета DAVIS
├── videos/      # предварительно обработанные видео
└── results/     # восстановленные видео
```

### Структура проекта

```text
.
├── create-data.ipynb       # подготовка видео и генерация масок
├── video-inpainting.ipynb  # модель и восстановление видео
└── data/
    ├── DAVIS/              # исходные видео
    ├── videos/             # обработанные видео
    └── results/            # восстановленные видео
```
